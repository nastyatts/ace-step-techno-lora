# Подготовка данных и дообучение ACE-Step для генерации techno

Проект посвящён адаптации музыкальной генеративной модели ACE-Step с использованием LoRA. Основные этапы — подготовка аудиодатасета, автоматическое формирование текстовых описаний и проведение дообучения.

## Данные и предобработка

Подготовлен датасет из **53 367 аудиофрагментов из 4 671 исходного трека**. Суммарная длительность фрагментов составляет около **445 часов** с учётом перекрытий между соседними фрагментами. В выполненных экспериментах обучающая часть содержала **48 000 фрагментов**.

| Параметр | Значение |
|---|---|
| Жанровая направленность | Techno |
| Формат фрагментов | FLAC, стерео |
| Частота дискретизации | 44,1 кГц |
| Длительность фрагмента | 30 секунд |
| Перекрытие соседних фрагментов | 5 секунд |

Этапы подготовки:

1. Фильтрация каталога музыкальных метаданных по speechiness и BPM и сопоставление записей с локальными аудиофайлами.
2. Проверка читаемости аудио через `ffprobe` и удаление точных файловых дубликатов по SHA-1: исключено 376 дубликатов.
3. Нарезка аудио: получено 62 743 фрагмента.
4. Автоматическая фильтрация по распознанному тексту через Whisper: исключено 3 648 фрагментов, осталось 59 095.
5. Исключение всех 5 728 фрагментов с категорией `sampled vocal texture`: итоговый объём — 53 367 фрагментов. Эта дополнительная фильтрация сокращает количество вокального материала.

## Автоматическая подготовка описаний

Текстовое условие для каждого фрагмента строится из характеристик исходного трека и самого аудиофрагмента.

| Источник | Характеристики и теги |
|---|---|
| Spotify | Энергия, настроение, танцевальность и инструментальность исходного трека |
| librosa | Яркость звучания, плотность ритма, атака ударных и текстура отдельного фрагмента |
| CLAP | Top-3 семантических аудиотега, например `acid techno`, `ambient techno`, `dark melodic techno` |

Для акустического анализа извлекаются спектральные, тембральные и ритмические признаки, включая MFCC, chroma и характеристики onset. Часть признаков преобразуется в теги с помощью правил и квантилей. Семантические теги определяются моделью `laion/clap-htsat-unfused`.

**Qwen3 8B через Ollama** преобразует итоговый набор тегов в связное англоязычное описание. Повторяющиеся наборы тегов обрабатываются с использованием кеша. Вместе с описанием сохраняются BPM, тональность и музыкальный размер.

На этапе генерации описаний для 59 095 фрагментов обработано 40 272 уникальных набора тегов. Затем из этой таблицы получен итоговый вариант с исключённой категорией `sampled vocal texture`.

Для каждого примера сохраняются идентификатор исходного трека, путь к аудио, длительность, музыкальные метаданные, теги и описание. Поддерживаются общий промпт `techno music, electronic music` и подробные описания, учитывающие характеристики фрагмента.

Пример музыкальных метаданных из подготовленного датасета:

```json
{
  "caption": "A dark, high-energy techno track with a steady groove, soft drum attack, and balanced texture.",
  "bpm": 142.013,
  "keyscale": "G minor",
  "timesignature": "4"
}
```

## Дообучение

Для адаптации ACE-Step проведены четыре эксперимента с LoRA, различающиеся рангом адаптера, alpha и числом эпох.

| Вариант | Rank (`r`) | Alpha (`α`) | Эпохи |
|---|---:|---:|---:|
| `rank4` | 4 | 16 | 1 |
| `rank4_2ep` | 4 | 16 | 2 |
| `rank8` | 8 | 32 | 1 |
| `rank16` | 16 | 32 | 1 |

Общие параметры выполненных экспериментов:

| Параметр | Значение |
|---|---|
| Batch size | 1 |
| Gradient accumulation steps | 8 |
| Learning rate | `2e-5` |
| Оптимизатор | AdamW |
| Точность вычислений | fp16 |
| Обучающих примеров | 48 000 |

Метаданные экспортируются в формат обучающего backend. В обучающий манифест включаются только строки с `split=train`. После подготовки аудио в тензорном формате запускается обучение LoRA-адаптера. Для генерации используются базовая модель и выбранный адаптер.

## Разбиение в текущей версии скриптов

Текущая версия кода назначает train/validation/test **по исходным трекам**: все фрагменты одного трека получают одну метку. При наличии нескольких путей к одному треку они связываются через `trackUri`; при отсутствии метаданных исходный трек определяется по имени фрагмента вида `..._chunk_0000.flac`.

Разбиение воспроизводится с `seed=42`. Пропорции 90/5/5 задаются по числу треков, поэтому доли аудиофрагментов могут немного отличаться. Для готовой CSV доступен скрипт `scripts/resplit_metadata.py`, обновляющий разбиение без повторной обработки аудио или генерации описаний.

## Установка и запуск

Команды выполняются из корня репозитория. Для Python рекомендуется отдельное виртуальное окружение.

```bash
pip install -r requirements.txt
```

Дополнительно нужны FFmpeg/ffprobe, локальный Ollama для текстовых описаний и отдельно установленный совместимый backend ACE-Step с весами модели. Скрипты обучения ожидают интерфейс `train.py fixed` с подготовкой тензоров и LoRA-обучением; внешняя реализация и веса в этот репозиторий не входят.

Пути к backend и весам задаются в `configs/train_lora.yaml`. Файл содержит стартовую конфигурацию. Для запуска с параметрами одного из описанных экспериментов нужно установить `batch_size: 1`, `gradient_accumulation_steps: 8`, `learning_rate: 2e-5`, `optimizer_type: adamw`, `mixed_precision: fp16`, а также `lora_rank`, `lora_alpha` и `epochs` выбранного варианта.

После установки внешнего backend его расположение проверяется командой:

```bash
python scripts/setup_acestep.py
```

Эта команда создаёт локальный диагностический файл `configs/acestep_detected.json`. Исходное аудио и таблицы метаданных пользователь предоставляет отдельно.

### Основные команды

```bash
python scripts/clean_dataset.py --input_dir data/dirty_data --output_dir data/raw_clean
python scripts/prepare_dataset.py --input_dir data/raw_clean --output_dir data/processed --chunk_seconds 30 --overlap_seconds 5 --sample_rate 44100
```

Для подготовки описанных выше метаданных с тегами используются `classify_chunks_text.py`, `build_final_prompt_tags.py` и `rewrite_captions_ollama.py`. Параметры входных таблиц и моделей доступны через `--help`. `make_metadata.py` предоставляет альтернативную подготовку описаний на основе акустических признаков и кластеризации.

Если итоговая таблица уже подготовлена, разбиение можно обновить отдельно:

```bash
python scripts/resplit_metadata.py --input_csv data/metadata_final_prompt_tags_ollama_drop_sampled_vocal.csv --output_csv data/metadata_track_split.csv
```

Для нового запуска обучения указать нужную таблицу в `training.metadata_path` конфига. Затем экспортировать манифест и запустить обучение:

```bash
python scripts/train_lora.py --config configs/train_lora.yaml --prompt_mode features --run
```

Для нового эксперимента с изменённым разбиением используются свежие обучающие тензоры и новый адаптер. Примеры генерации создаются через `scripts/generate_samples.py`; путь к адаптеру передаётся аргументом `--checkpoint_dir`.
